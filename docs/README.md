# 文档目录

- `architecture/`：以“GraphPTC 创新点与方法总结”为论文方法主线；完整实现框架作为工程参考。
- `benchmarks/`：外部环境、数据准备、官方 evaluator 和运行说明。
- `development/`：研究日志和未晋级 challenger 的开发记录。
- `handoffs/`：面向后续维护者和 Codex 的交接信息。
- `benchmark-results.md`：当前所有已接入 benchmark 的结果口径和证据路径。
- `dataset-setup.md`：六项正式重测的官方数据来源、固定 revision、下载命令、目录和验收标准。
- `server-evaluation.md`：老师在 Linux 服务器上安装、切换模型、预检和启动全量三组评测的主入口。

根目录 README 只保留项目入口和最短运行路径；长环境说明应写入对应 benchmark 文档。
